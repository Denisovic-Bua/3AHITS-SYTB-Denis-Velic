## Theorie
**Kurze Zusammenfassung:**
In Linux-Systemen ist das **Bash Scripting** ein Werkzeug, um repetitive Aufgaben zu automatisieren. Skripte ermöglichen es, Kontrollstrukturen wie Schleifen (`for`, `while`) und Bedingungen (`if-else`) direkt auf der Kommandozeile oder in einer ausführbaren Datei zu nutzen. Durch die Verwendung von Argumenten, die beim Aufruf übergeben werden, können Skripte dynamisch mit verschiedenen Daten arbeiten, ohne dass man den Code jedes Mal anpassen muss.

**Wichtigsten Bausteine:**
- `for i in {1..42}`: Eine Standard-Schleife, die eine Variable `i` von einem Startwert bis zu einem Endwert hochzählt.
- `$@`: Ein spezieller Platzhalter, der für **alle** Argumente steht, die dem Skript beim Aufruf übergeben wurden. Ideal, wenn man nicht weiß, wie viele Zahlen der User eingibt.
- `(( ... ))`: Arithmetische Evaluation in Bash. Wird verwendet, um mathematische Berechnungen (wie Modulo `%` oder Vergleiche) performant und direkt durchzuführen.
- `cat "datei" | xargs`: Ein cooler Trick, um den Inhalt einer Datei (selbst wenn Zahlen wild durch Whitespaces oder neue Zeilen getrennt sind) nacheinander in eine einfache Schleife einzuspeisen.

## 1. Übung (Even/Odd)
Create a simple script which will print the numbers 1–42 (each on a separate line) and whether they are even or odd.

**Regeln:**
  - Zahlen von 1 bis 42 durchlaufen
  - Jede Zahl auf einer neuen Zeile ausgeben
  - Prüfen, ob die Zahl gerade (even) oder ungerade (odd) ist

---
### Lösung:

```sh
#!/bin/bash

# Schleife von 1 bis 42 durchlaufen
for i in {1..42}
do
    # Mit Modulo prüfen ob der Rest bei Division durch 2 gleich 0 ist
    if (( i % 2 == 0 )); then
        echo "$i ist even"
    else
        echo "$i ist odd"
    fi
done
