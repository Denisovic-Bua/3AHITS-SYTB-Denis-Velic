## Theorie
In der Bash prüft if den Erfolg von Befehlen oder Bedingungen wobei die eckigen Klammern `[ ]` als test Kommando für Datei und Textchecks dienen. Für reine Zahlenvergleiche nutzt man die Arithmetik-Klammern `(( ))`, die eine einfache Schreibweise ohne viele Dollarzeichen ermöglichen. Logische Verknüpfungen wie && (Und) oder || (Oder) erlauben es zudem, mehrere Abfragen effizient in einer Zeile zu bündeln. Also sehr ähnlich wie in Programmiersprachen wie `C`



## 1. Übung Maximum

Schreibe ein bash Skript das 2 Zahlen als Argumente aus der Kommandozeile übernimmt. Die größere der beiden Zahlen soll ausgegeben werden.

**max.sh:**
```sh
#!/bin/bash
if [ $1 -gt $2 ]
then
  echo $1
else
  echo $2
fi
```
**Ausgabe:**
```sh
./max.sh 6 7
7
```
`-gt` steht für `greater than` also größer als

## 2. Übung Un-/Gerade

Schreibe ein Script das von einer als Argument übergebenen Zahl prüft ob sie gerade oder ungerade ist.

**gerade.sh:**
```sh
#!/bin/bash

# Prüfen, ob der Rest bei Teilung durch 2 gleich 0 ist
if [ $(( $1 % 2 )) -eq 0 ]; then
    echo "Die Zahl $1 ist gerade."
else
    echo "Die Zahl $1 ist ungerade."
fi

```
**Augabe:**
```sh
./gerade.sh 4
Die Zahl 4 ist gerade

./gerade.sh 7
Die Zahl 7 ist ungerade
```

Hier wird einfach das erste Argument `$1` Modulo 2 gerechnet und geschaut ob es 0 ergibt
`-eq` steht für `equals` also ist gleich z.B.: *0* 

## 3. Übung Directory
Ein Directory mit dem Namen `xyz` soll angelegt werden falls es nicht existiert. Im Directory lege eine Datei mit dem Namen `xyz.txt`.

**makedir.sh:**
```sh
#!/bin/bash

DIR=$1

# Schauen ob es noch nicht existiert 
if [ ! -d "$DIR" ]; then
    mkdir "$DIR"
    echo "$DIR" > "$DIR/$DIR.txt"

# Wenn es das verzeichnis schon gibt
else
    # Dateien zählen
    FILES=$(ls "$DIR" | wc -l)
    
    echo -n "Soll das Directory \"$DIR\" (mit $FILES Files) gelöscht werden? [j|n]: "
    read ANTWORT

    if [ "$ANTWORT" = "j" ]; then
        rm -r "$DIR"
        mkdir "$DIR"
        echo "$DIR" > "$DIR/$DIR.txt"
    fi
fi

```

**Ausgabe:**
```sh
./makedir.sh xyz
Soll das Directory "xyz" ( mit 1 Files ) gelöscht werden? [j|n]:
j
```

Hier wird am anfang geschaut ob es das Verzeichnis mit dem Namen schon exisitiert, falls nicht wir eins Erstellt und eine Text datei mit dem selben namen in dem Verzeichnis wird auch erstellt. Falls es doch keins gibt wird erst gezählt wie viele Files es in dem Ordner gibt und danach gefragt ob man das verzeichnis löschen will mit einer `[j|n]` abfrage. 

## 4. Übung Stundenplan V2
Schreibe ein Skript das aufgrund der aktuellen Zeit das aktuell Fach laut Stundenplan ausgibt. Pausen sind vereinfacht einem Fach zuzurechnen. Berücksichtige nur einen Wochentag, d.h. das Skript funktioniert nur an einem Donnerstag.

**splan2.sh:**
```sh
#!/bin/bash

# Die jetzige Zeit speichern 
JETZT=$(date +%-H%M)

echo -n "Donnerstag $(date +%H:%M) Uhr: "

# Mit der Stunde vergleichen

if [ $JETZT -gt 1510 ]; then
    echo "Schule aus"
elif [ $JETZT -gt 1420 ]; then
    echo "D"
elif [ $JETZT -gt 1325 ]; then
    echo "Mittagspause"
elif [ $JETZT -gt 1140 ]; then
    echo "BESP"
elif [ $JETZT -gt 1045 ]; then
    echo "ITP2PM"
elif [ $JETZT -gt 940 ]; then
    echo "SYTE"
elif [ $JETZT -gt 845 ]; then
    echo "AM"
elif [ $JETZT -gt 750 ]; then
    echo "NW2-p"
else
    echo "Schule noch nicht begonnen"
fi


```

**Ausgabe:**
```sh
./splanv2
Donnerstag 09:10 AM
```

`-gt` wie besprochen steht für `greater than`. Was das script hier macht er vergleicht die jetzige Zeit mit der Zeit von der Stunde am Donnerstag, das heißt wenn die Zeit größer als `7:50 = 750` hat die erste Stunde begonnen `NW2-P` usw.
